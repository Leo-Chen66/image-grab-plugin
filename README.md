# 图提取 ImageGrab — Chrome 电商图片批量下载插件

在淘宝、京东、拼多多商家版商品详情页**一键提取所有商品图片**，新页面集中预览、自由勾选、批量下载为 PNG。

## 安装步骤

1. 把 `image-grab-plugin` 文件夹放到本地任意位置
2. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
3. 打开右上角「开发者模式」开关
4. 点击「加载已解压的扩展程序」，选择本文件夹
5. 打开支持的商品详情页，右下角会出现「获取图片」悬浮按钮

## 使用方法

1. 在商品详情页点击右下角「获取图片」
2. 自动打开图片画廊页，展示提取到的所有图片及尺寸信息
3. 勾选需要的图片（支持全选 / 反选，顶部实时显示已选数量）
4. 点击「下载选中」，图片自动转换为 PNG 并保存到浏览器默认下载目录

下载文件名规则：`商品图_001.png`（序号自动补零）。

## 支持页面

- 淘宝：`item.taobao.com/item.htm`
- 天猫：`detail.tmall.com/item.htm`
- 京东：`item.jd.com/数字.html`
- 拼多多：`yangkeduo.com/goods.html`、商家后台 `mms.pinduoduo.com`

## 功能特性

- **一键提取**：扫描 `<img>`、`srcset`、`data-src` 等懒加载属性与背景图
- **智能过滤**：排除图标、logo、占位图、1x1 像素图、小于 100×100 的图片
- **集中预览**：新标签页网格化展示，带缩略图与尺寸信息
- **自由勾选**：全选 / 反选 / 按需下载
- **统一 PNG**：jpg / webp 等格式自动通过 canvas 转换为 PNG
- **批量下载**：一键保存，带进度条与结果反馈

## 常见问题

- **按钮没出现？** 确认当前页面是受支持的商品详情页，并刷新页面重试。
- **部分图片下载失败？** 个别图片有强防盗链或已失效，插件会跳过并在完成后提示失败数量。
- **下载的图片在哪？** 浏览器默认下载目录（Chrome 设置 → 下载内容可查看）。
