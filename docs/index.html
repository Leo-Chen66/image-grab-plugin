产品介绍

为什么做这个插件

🧩

图片分散难收集

电商详情页的主图、细节图、长图散落在页面各处，还大量使用懒加载，右键另存一张张点，费时费力。

📦

批量保存没工具

浏览器自带的保存功能只能存单张图，无法按需筛选，也无法自动编号整理，素材多了就乱。

🖼️

格式杂乱不统一

jpg、webp、avif 混在一起，上传素材库或交付设计时经常要重新转格式，来回折腾。

图提取 ImageGrab 把「找图 → 挑图 → 存图」压缩成一次点击：自动扫描全页商品图， 画廊集中预览，勾选后统一转 PNG、按序号命名，一键保存到本地。

核心功能

六个特性，覆盖提取到下载的完整链路

⚡

一键提取

自动扫描页面所有商品图，兼容 data-src、srcset、背景图等懒加载写法。

🎯

智能过滤

自动排除图标、logo、占位图与小于 100×100 的小图，只留下有用的商品素材。

🗂️

集中预览

提取结果在新页面网格化展示，每张图带缩略图与尺寸信息，一目了然。

✅

自由勾选

支持全选、反选与按需勾选，顶部实时统计已选数量，要哪几张自己定。

🔄

统一 PNG

jpg / webp 等格式自动通过 canvas 转换为 PNG，交付格式永远统一。

📥

批量下载

一键保存到本地，文件名自动编号（商品图_001.png），下载过程有进度提示。

安装步骤

四步装好，无需任何依赖

  1. 1

    下载并解压插件

    点击页面底部「下载插件」，把压缩包解压到一个固定文件夹。

  2. 2

    打开扩展管理页

    打开 Chrome，地址栏输入 chrome://extensions 后回车。

  3. 3

    开启开发者模式

    打开扩展管理页右上角的「开发者模式」开关。

  4. 4

    加载插件

    点击「加载已解压的扩展程序」，选择解压后的文件夹，完成！
